# Travel plan

A static travel-planning page in Japanese and Simplified Chinese.

- Japanese: [index.html](index.html)
- 简体中文: [zh.html](zh.html)
- Photos, styles, and scripts are served with the site.
- Google Maps embeds load only when requested by the reader.
- Reservation confirmation codes are omitted from this public copy.

This repository and its GitHub Pages site are public. A random URL and search-engine indexing directives are not access controls.

Publish the main branch from the repository root with GitHub Pages. Review all future updates for private information before committing them.
